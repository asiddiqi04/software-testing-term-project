# tests-stripped

Suite 2: the assertion-stripped control. Generated by
`scripts/make-stripped.mjs` from `tests-codex/`. Do not edit by hand; run
`npm run make:stripped` to regenerate.

Each file is identical to its Codex original except that the
`node:assert/strict` import points at `_assert-stub.mjs`, where every assertion
is a no-op. `throws`/`rejects` still run the code and swallow the result.
