# tests-codex

Codex's original tests are added after the human tests are written.

This folder holds the tests OpenAI Codex wrote for ShadowBoxer while building
it, unedited, at source commit `c023fef`. They are kept out of the repo until
the human-written suites in `tests-human/` are finished, so the human testers
cannot see them (see the blind rule in `CONTRIBUTING.md`).

When they are added, the files must be byte-identical to the originals and
must match the checksums recorded before the study started.
